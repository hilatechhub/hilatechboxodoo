Frequently asked questions

Does it work with Odoo Enterprise?

No. It is designed for Odoo 19 Community, which does not include the Enterprise home menu and apps sidebar. It has not been tested on Enterprise.

Do I need other modules?

No. The module is self-contained and only depends on web and base_setup. Do not install ica_web_responsive or muk_web_appsbar together with it: it already includes that functionality.

Can each company have its own colors?

Yes. Colors, favicon, backgrounds and sidebar logo are stored per company.

Can I go back to the default look?

Yes. Leave a color empty to keep the Odoo default, or uninstall the module.
